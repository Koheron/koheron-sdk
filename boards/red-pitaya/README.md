# STEMlab 125-14

Build target: `red-pitaya`. This package supports the original board; see the
[Gen 2 board support guide](../red-pitaya-gen2/README.md) for the newer variants.

## Description

The STEMlab 125-14 is a small network-attached instrument based on the Zynq 7z010 SoC.
It features two analog inputs and two analog outputs, both with 14 bits resolution and 125 MHz sampling frequency.
